## 安装后怎样测试

1. Windows 双击单文件 EXE；Android 安装 ARM64 APK。名称包含 M1 Preview，Android 与正式版并存；默认服务地址为 `http://127.0.0.1:11436`。测试包使用独立数据，不自动携带现用模型／路由配置。
2. 进入「开始」，保持「交给我回答」，填写一个无害问题和两个候选，提交后进入「决策台」。先点选，确认尚未提交，再点击提交回答。
3. 通过指南中的调用 Token／HTTP 例子提交外部任务，取回同一 ID 的结果。尝试拒答、附条件、取消，以及关闭／重开应用后恢复。完整退出与仅隐藏到托盘不同。
4. 在路由／提供商／演练场等页面确认原操作仍在。模型实测需要在独立测试配置中登记来源；人工作答本身无需模型、LLM API 或上游 key。
5. Android 真机进一步检查键盘、旋转、后台／通知／tile 与设备 OEM 行为；这些新候选的人工结果不能由模拟器代签。新任务提醒尚未进入 M1，请主动打开决策台查询。

- 当前无完整多用户账号、远端主人配对、人工来源 DAG 策略、Score／Noul／Box 人工补全或实验闭环。one-hot 的 1 是离散编码，不能解释成测得的置信度。
