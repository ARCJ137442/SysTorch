## 发布门禁中发现并修复的问题

- SVG 哈希门禁曾把 Windows checkout 的 CRLF 当作主图变化；现在规范化换行后校验 SVG 文本，同时继续严格校验 PNG/ICO 等二进制派生物。
- Docker UI 构建缺少生成 TypeScript 类型引用的绑定目录；现在同时复制 `jev-protocol` 与 `systorch-daemon` 两个仍被引用的绑定目录。
- Android WRY 构建曾把生成 Kotlin 输出写入旧 `jevswitch` 包，与新 Android namespace 不一致；现在从 `tauri.android.conf.json` 的 `identifier` 派生 Kotlin 包和输出目录，稳定 `applicationId` 仍保持 `io.github.arcj137442.jevswitch`。
- Release job 之前未 checkout 源码，导致 `body_path` 找不到双语说明；当前发行页已补正文，workflow 也已在 main 修复为先 checkout tag，并由 main CI `40982136055` 验证通过。
